# MiloshVPN WebApp

This directory contains the standalone Telegram Mini App frontend.

Structure:

- `admin/` - admin web app entrypoint
- `user/` - user web app entrypoint
- `shared/` - shared assets, styles, and client logic

Current scope:

- Telegram Mini App auth bootstrap
- public plans/content loading
- user profile/subscription/access loading
- admin dashboard/plans/content/YooKassa settings loading

Next planned layers:

- purchase flow via YooKassa
- editable admin forms
- Marzban server management
- analytics charts
